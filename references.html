About these sources

We used the official documentation because Supabase changes quickly and secondary articles go out of date. Where a fact depends on the date, such as pricing or a product name, the access date is given. The example code adapts patterns from the Supabase JavaScript reference and guides; the schema, policies, tests and pages are our own work.

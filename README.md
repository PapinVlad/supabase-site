# Supabase · COMP10020 Coursework 1 · Group B

Learning site for our Supabase presentation: slides with notes, a one-hour tutorial, a cheat sheet and references.

Website: https://papinvlad.github.io/supabase-site/

## Contents

- `index.html`: the website (GitHub Pages serves it from the repository root)
- `app/`: the example app used in the presentation (added later)

## Run the example app locally

Copy `app/config.example.js` to `app/config.js`, add your own project URL and publishable key, then serve the folder:

```
python3 -m http.server 8000
```

Never commit `config.js`, passwords, or a secret / service_role key.
